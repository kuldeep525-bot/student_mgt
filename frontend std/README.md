# Frontend for stdMgt

# 📚 Student Notes & Papers Platform – Frontend

This is the **frontend** of the Student Notes & Papers Platform built using **React + Vite + Tailwind CSS**.  
The platform allows students to access notes, purchase exam papers, and manage their learning resources.  
It also includes an **Admin Dashboard** to manage users, papers, and payments.

---

# 🚀 Tech Stack

- React.js
- Vite
- Tailwind CSS
- DaisyUI
- Axios
- React Router DOM
- Framer Motion
- React Toastify
- Recharts
- QR Code Generator
